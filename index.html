Politica de Privacidade

Ultima atualizacao: 5 de agosto de 2026

Esta Politica de Privacidade explica como o LPFeira trata os dados utilizados para oferecer controle de vendas, produtos e financeiro para feirantes e pequenos negocios.

Dados que tratamos

O LPFeira pode tratar os seguintes dados quando voce utiliza o aplicativo:

  • Nome, endereco de e-mail e foto de perfil fornecidos no login com Google.
  • Nome do estabelecimento e preferencias de uso informadas por voce.
  • Produtos, categorias, precos, vendas, formas de pagamento e fechamentos cadastrados no app.
  • Informacoes de assinatura recebidas da Google Play, como status e periodo de validade.

Como os dados sao usados

Os dados sao usados somente para identificar sua conta, sincronizar suas informacoes entre instalacoes do aplicativo, apresentar indicadores financeiros e controlar o acesso ao periodo gratuito ou a assinatura contratada.

Armazenamento e seguranca

Os dados operacionais sao armazenados no Supabase, com regras que restringem o acesso aos dados da propria conta autenticada. As conexoes do aplicativo utilizam HTTPS. O LPFeira nao utiliza backup automatico do Android para os dados do aplicativo.

Pagamentos

Assinaturas sao processadas pela Google Play. O LPFeira nao recebe nem armazena dados completos de cartao. As informacoes de compra necessarias para validar o acesso sao verificadas de forma segura com os servicos do Google Play.

Compartilhamento

Nao vendemos dados pessoais e nao usamos os dados para publicidade. Os dados podem ser tratados pelos provedores necessarios para o funcionamento do aplicativo: Google, para autenticacao e pagamentos, e Supabase, para armazenamento e sincronizacao.

Seus controles

Voce pode alterar seus dados operacionais diretamente no aplicativo e solicitar orientacao sobre sua conta pelo canal de contato abaixo. A exclusao dos dados cadastrados no app pode ser feita pelas configuracoes do aplicativo.
